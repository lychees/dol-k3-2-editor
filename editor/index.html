Uncharted Waters — 编辑器套件

在线版：lychees.github.io/dol-k3-2-editor 直接读取游戏站点的公开数据，导出后的文件需手动合并回游戏仓库。 本地版：在游戏仓库的 game/ 目录运行 python -m http.server 8734，打开 http://127.0.0.1:8734/editor/，此时直接读写本地 game/assets/。 修改后点击「导出」下载文件，用它覆盖 game/assets/ 中的同名文件即可生效。 修改不会影响已存在的游戏存档（localStorage），新游戏或重置后生效。
